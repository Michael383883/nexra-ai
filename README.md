# NEXRA AI

Aplicación de escritorio para Windows 11 que organiza proyectos, prepara contexto y gestiona cambios de código
usando los asistentes web (Claude, ChatGPT, Gemini) mediante navegador y portapapeles, con aprobación del usuario.

## Requisitos
- Node.js LTS
- Git

## Uso
```bash
npm install
npm run dev     # modo desarrollo (Vite + Electron)
npm start       # compila y abre la app
```
